## 💡 Como Contribuir

Achou um erro em alguma fórmula? Tem uma maneira mais otimizada de fazer o mesmo `JOIN` no Python? 

1. Faça um Fork do repositório
2. Crie sua Feature Branch (`git checkout -b feature/minha-melhoria`)
3. Faça o Commit das suas alterações (`git commit -m 'feat: Melhoria na aba Lookup do Excel'`)
4. Faça o Push para a Branch (`git push origin feature/minha-melhoria`)
5. Abra um Pull Request.

Toda ajuda é bem-vinda para tornar este guia a referência número 1 para a comunidade de dados do Brasil!
